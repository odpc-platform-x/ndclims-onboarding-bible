ใบสั่งตรวจเข้ามา 2 ทาง

(A) อัตโนมัติจาก รพ./เครือข่าย
แล็บที่เชื่อมระบบแล้ว — ดูที่เมนู "รับเข้าจาก สคร./รพ." ระบบจับคู่ผู้ป่วยด้วยเลขบัตรประชาชนแล้ว HN ให้เอง ไม่ต้องกรอกซ้ำ
(B) ใบส่งตรวจกระดาษ
หน่วยงานส่งใบกระดาษมา — กรอกเองในหน้าถัดไป (ค้นหา/ลงทะเบียนผู้ป่วย + สั่งตรวจ)
เมนู "รับเข้าจาก สคร./รพ." มีเฉพาะแล็บที่เชื่อมระบบแล้วเท่านั้น (เปิดตามแพ็กเกจ)

งานประจำวัน 2/6 · เจ้าหน้าที่บันทึกข้อมูล

ค้นหา/ลงทะเบียนผู้ป่วย + สั่งตรวจ

  • ค้นหาก่อนเสมอ — ช่อง "ค้นหา HN, ชื่อ-นามสกุล, เลขบัตรประชาชน..."
  • ไม่พบจึงกด "ผู้ป่วยใหม่" — ใช้ปุ่ม "อ่านบัตรประชาชน" ช่วยกรอกเร็วขึ้น
  • ขึ้นเตือน "พบข้อมูลผู้ป่วยที่คล้ายกัน" — ตรวจสอบแล้วใช้คนเดิม อย่าสร้างใหม่
  • สั่งตรวจ: เลือกรายการตรวจ + ระบุ "หน่วยงานที่ส่งตรวจ" → รอดำเนินการ, ใบแจ้งหนี้สร้างอัตโนมัติ
สร้างผู้ป่วยซ้ำ = ประวัติแตกสอง HN — ค้นหาก่อนทุกครั้ง

รับสิ่งส่งตรวจ

  • เปิดเมนู รับสิ่งส่งตรวจ → เปิด "เปิดสแกนบาร์โค้ด" แล้ววางเคอร์เซอร์สแกน
  • หาใบสั่งตรวจที่รอ แล้วกดปุ่ม "รับ" → กำลังตรวจ
  • กด "พิมพ์ฉลาก" (หรือ "พิมพ์ฉลากที่เลือก") ติดหลอดตัวอย่าง
  • สิ่งส่งตรวจใช้ไม่ได้? กดปุ่ม "ปฏิเสธ" แทน (ดูสไลด์ข้อผิดพลาด)
ยังไม่กด "รับ" = บันทึกผลไม่ได้

บันทึกผล + Verify

  • กรอกค่าผลตรวจทีละรายการ → กด "บันทึก" → บันทึกผลแล้ว
  • ผู้ตรวจ (อาจเป็นคนละคนกับคนบันทึก) กด "Verify" → ตรวจสอบแล้ว
  • กรอกผิด? กด "ยกเลิก Verify" ถอยกลับมาแก้ได้ — ระบบเก็บประวัติการแก้ไข
ค่าวิกฤตต้องกรอก "บันทึกการแจ้ง" ในหน้าต่าง Critical Value ก่อนถึงจะบันทึก/Verify ได้

พิมพ์ / ส่งผล รพ. + วางบิล

พิมพ์ / ส่งผล รพ.
เปิดใบสั่งตรวจ → "พิมพ์ใบรายงานผล" → บันทึกเป็น PDF → ส่งจากอีเมลแล็บไปที่อีเมลที่ รพ. แจ้งไว้ — รพ. ที่มีบัญชี Portal ดู/พิมพ์ผลเองได้
วางบิล รพ.
ใบแจ้งหนี้ในระบบเป็นรายผู้ป่วย · วางบิล รพ. ทำนอกระบบ · ดูยอดค้างที่ การเงิน > ลูกหนี้คงค้าง · รพ. โอนแล้ว → เปิดใบแจ้งหนี้ → ชำระ "โอนเงิน"
ปุ่ม "ส่งผลทางอีเมล" ในระบบส่งถึงอีเมลผู้ป่วย ไม่ใช่ รพ. · รพ. โทรถามผล → "ค้นหาสิ่งส่งตรวจ" ดูสถานะ (เสร็จสิ้น = อนุมัติครบ)

สิ่งส่งตรวจเสีย / ต้องยกเลิกใบ

สิ่งส่งตรวจใช้ไม่ได้
หน้า "รับสิ่งส่งตรวจ" กดปุ่ม "ปฏิเสธ" → กรอกเหตุผล (บังคับ) → เช็กบ็อกซ์ "ขอเก็บตัวอย่างใหม่ (สร้างภาชนะทดแทน)" ติ๊กอยู่แล้วโดยปริยาย → ระบบสร้างภาชนะทดแทนให้เก็บใหม่
ต้องยกเลิกใบสั่งตรวจ
ปุ่ม "ยกเลิกใบสั่งตรวจ" ขึ้นเฉพาะตอน รอดำเนินการ · ต้องใส่เหตุผล · ใบแจ้งหนี้ยกเลิกตาม · กำลังตรวจแล้ว ระบบยกเลิกไม่ได้เลย — แจ้งหัวหน้าห้องปฏิบัติการตัดสินตามระเบียบแล็บ
โทร/อีเมลแจ้ง รพ. ผู้ส่งทุกครั้ง — ระบบไม่แจ้งให้ · พิมพ์หลักฐาน: รายงาน > ปฏิเสธตัวอย่าง > "พิมพ์ A4"
เมื่อเกิดข้อผิดพลาด 2/2

กรอกผลผิด / ค่าวิกฤต

ยังไม่ Verify — แก้ค่าได้เลยในหน้าบันทึกผล
Verify แล้ว — กด "ยกเลิก Verify" ให้ถอยเป็น บันทึกผลแล้ว ก่อนแล้วค่อยแก้
Approve แล้ว — ต้องให้ผู้มีสิทธิ์ Approve กด "ยกเลิก Approve" ก่อนแล้วค่อยแก้
ทุกการแก้ไขมีประวัติการแก้ไขผล เก็บไว้เสมอ ไม่มีการเขียนทับเงียบๆ
ค่าวิกฤต: หน้าต่าง "ค่าวิกฤต — Critical Value" เด้งก่อนบันทึก/Verify/Approve — ระบบอีเมลแจ้งผู้ติดต่อของ รพ. อัตโนมัติ (ไม่แสดงค่าผล) ยังต้องโทร/อีเมลแจ้งตามระเบียบแล็บ แล้วกรอก "บันทึกการแจ้ง" (เช่น โทรแจ้ง รพ.X คุณ... เวลา...) แล้วกด "รับทราบและบันทึก"

  • รพ. ส่งใบกระดาษ ได้ผลทางไหน? — พิมพ์ใบรายงานผลเป็น PDF ส่งทางอีเมลที่ รพ. แจ้งไว้ (ปุ่มส่งผลทางอีเมลในระบบส่งถึงผู้ป่วยเท่านั้น)
  • สิ่งส่งตรวจใช้ไม่ได้ทำยังไง? — กด "ปฏิเสธ" + ขอเก็บตัวอย่างใหม่ แล้วโทร/อีเมลแจ้ง รพ.
  • Approve ไปแล้วแต่ค่าผิด ทำยังไง? — แจ้งผู้มีสิทธิ์ Approve ให้กด "ยกเลิก Approve" แล้วแก้ ระบบเก็บประวัติ

Lab admin · 1 ชั่วโมง
เข้าระบบครั้งแรก
ฝ่าย IT กรมติดตั้งระบบและสร้างบัญชี admin ของแล็บไว้ให้แล้ว — งานของคุณคือเข้าระบบให้ได้จริง เปลี่ยนรหัสผ่าน แล้วตรวจชื่อแล็บ
  • รับ URL ระบบ + บัญชี admin จาก ฝ่าย IT กรม แล้วลอง login ให้ได้จริง
  • เปลี่ยนรหัสผ่านทันทีที่เข้าได้ครั้งแรก (ตั้งค่า > ความปลอดภัย > "เปลี่ยนรหัสผ่าน") — รหัสเริ่มต้นไม่ใช่ความลับถาวร
  • ตรวจว่าชื่อแล็บ / ชื่อสาขา ที่ขึ้นบนหน้าจอสะกดถูก — ผิดแจ้ง IT ทันที

Lab admin · 5–10 วัน
ซ้อมใช้งานจริงระดับแล็บ
ขั้นนี้คือสิ่งเดียวที่กันความหายนะวันเปิดใช้จริง
  • เลือกงานจริงวันละ 10–20 เคส เดินให้ครบวงจร: ลงทะเบียนผู้ป่วย → สั่งตรวจ → รับสิ่งส่งตรวจ → บันทึกผล → Verify → Approve → พิมพ์ใบรายงานผล (เก็บเงินทำได้ทุกเวลา)
  • จดทุกอย่างที่ไม่ตรงหรือติดขัดลงรายการเดียว — ห้ามแก้ปากเปล่า
  • เจ้าหน้าที่ทุกคนต้องได้ลงมือทำเองอย่างน้อยคนละ 3 เคส ไม่ใช่แค่นั่งดู
