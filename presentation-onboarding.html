สลับไปหน้าจอระบบจริง
ให้ผู้เข้าอบรมดูการคลิกจริงทีละขั้น ก่อนไปดูรายละเอียดทีละขั้น
งานประจำวัน 1/5 · receptionist
ลงทะเบียนผู้ป่วย + สั่งตรวจ
  • ลงทะเบียนผู้ป่วย — คลิก "ผู้ป่วยใหม่" กรอกข้อมูล แล้วบันทึก → ได้ HN
  • สั่งตรวจ — เปิดผู้ป่วย → เลือกรายการตรวจ/แพ็กเกจ → สร้างใบสั่งตรวจ → รอดำเนินการ
  • สั่งตรวจได้ก็ต่อเมื่อมี "รายการตรวจ" อยู่ในระบบแล้วเท่านั้น — เป็นงานตั้งค่าที่ Lab admin ทำไว้ก่อน
งานประจำวัน 2/5 · lab_technician
รับตัวอย่าง
  • สแกน หรือเปิดใบสั่งตรวจที่ส่งมา
  • บันทึกวันเวลาที่รับตัวอย่างจริง — ไม่ใช่แค่เปิดดูใบสั่งตรวจเฉยๆ
  • บันทึกแล้ว สถานะขยับเป็น กำลังดำเนินการ
งานประจำวัน 3/5 · lab_technician
บันทึกผล
  • กรอกค่าผลตรวจทีละรายการในใบสั่งตรวจ
  • บันทึกแล้ว สถานะขยับเป็น รอตรวจสอบ
  • ผลที่บันทึกแล้ว ยังพิมพ์ใบรายงานไม่ได้ จนกว่าจะมีคนอนุมัติ
งานประจำวัน 4/5
อนุมัติผล + พิมพ์ใบรายงาน
  • lab_manager / doctorอนุมัติผล — ตรวจค่าที่บันทึก แล้วกดอนุมัติ → อนุมัติแล้ว
  • receptionist / lab_managerพิมพ์ใบรายงาน — เปิดใบที่อนุมัติแล้ว → พิมพ์ / ดาวน์โหลด PDF → พิมพ์แล้ว
  • ผลตรวจที่ยังไม่อนุมัติจะพิมพ์ใบรายงานไม่ได้ — กันผลหลุดออกไปก่อนมีคนตรวจสอบ
งานประจำวัน 5/5 · cashier
เก็บเงิน
  • เปิดใบสั่งตรวจ → รับชำระ → ออกใบเสร็จ
  • จบแล้ว สถานะขยับเป็น ปิดงาน — จบเส้นทางของใบสั่งตรวจนี้
  • บทบาทที่เขียนไว้ทั้งเส้นทางคือค่ามาตรฐาน — แล็บเล็กให้คนเดียวสวมหลายบทบาทได้ ตราบใดที่บัญชีมีสิทธิ์ครบ

งานของฉันตามบทบาท

บทบาท งานประจำวันในเส้นทางใบสั่งตรวจ ส่งต่อที่สถานะ
receptionist ลงทะเบียนผู้ป่วย + สั่งตรวจ · พิมพ์ใบรายงาน รอดำเนินการ / พิมพ์แล้ว
lab_technician รับตัวอย่าง + บันทึกผล กำลังดำเนินการ / รอตรวจสอบ
lab_manager อนุมัติผล · พิมพ์ใบรายงาน อนุมัติแล้ว / พิมพ์แล้ว
doctor อนุมัติผล อนุมัติแล้ว
cashier เก็บเงิน ปิดงาน
super_admin / company_admin / branch_admin ไม่อยู่ในเส้นทางใบสั่งตรวจประจำวัน — ดูแลระบบ/สาขาแทน —
ภาคผนวก C

บทบาทมาตรฐาน 8 แบบ

รหัส ชื่อ ระดับ ทำอะไรได้บ้าง
super_admin ผู้ดูแลระบบสูงสุด 0 ทุกอย่างในระบบ
company_admin ผู้ดูแลบริษัท 1 จัดการทุกสาขา ผู้ใช้ ผู้ป่วย แล็บ รายงาน การเงิน ตั้งค่า
branch_admin ผู้ดูแลสาขา 2 ดูสาขา + จัดการผู้ใช้ ผู้ป่วย แล็บ รายงาน การเงินในสาขา
lab_manager หัวหน้าห้องปฏิบัติการ 3 จัดการผู้ป่วย แล็บ รายงานเต็ม + ดูการเงิน
lab_technician นักเทคนิคการแพทย์ 3 ดูผู้ป่วย + สั่ง/บันทึกผลตรวจ + ดูรายงาน
receptionist พนักงานต้อนรับ 3 จัดการผู้ป่วย + สร้าง/ดูใบสั่งตรวจ + จัดการการเงิน
doctor แพทย์ 3 ดูผู้ป่วย + สั่งตรวจ + ดู/อนุมัติผลตรวจ + รายงานเต็ม
cashier แคชเชียร์ 3 ดูผู้ป่วย + ดูใบสั่งตรวจ + จัดการการเงิน
Lab admin · 1 ชั่วโมง
เข้าระบบครั้งแรก
IT ติดตั้งระบบและสร้างบัญชี admin ของแล็บไว้ให้แล้ว — งานของคุณคือเข้าระบบให้ได้จริง เปลี่ยนรหัสผ่าน แล้วตรวจชื่อแล็บ
  • รับ URL ระบบ + บัญชี admin จาก IT แล้วลอง login ให้ได้จริง
  • เปลี่ยนรหัสผ่านทันทีที่เข้าได้ครั้งแรก — รหัสเริ่มต้นไม่ใช่ความลับถาวร ทุกคนที่รู้ขั้นตอนติดตั้งมักรู้รหัสเดียวกัน
  • ตรวจว่าชื่อแล็บ / ชื่อสาขา ที่ขึ้นบนหน้าจอสะกดถูก — ผิดแจ้ง IT ทันที

ทุกฝ่าย · 5–10 วัน
ซ้อมใช้งานจริง
ขั้นนี้คือสิ่งเดียวที่กันความหายนะวันเปิดใช้จริง
  • เลือกงานจริงวันละ 10–20 เคส เดินให้ครบวงจร: ลงทะเบียนผู้ป่วย → สั่งตรวจ → รับตัวอย่าง → บันทึกผล → อนุมัติผล → พิมพ์ใบรายงาน → เก็บเงิน
  • จดทุกอย่างที่ไม่ตรงหรือติดขัดลงรายการเดียว — ห้ามแก้ปากเปล่า
  • เจ้าหน้าที่ทุกคนต้องได้ลงมือทำเองอย่างน้อยคนละ 3 เคส ไม่ใช่แค่นั่งดู
ทุกฝ่าย · หลังเปิดใช้จริง
สองสัปดาห์แรก
  • มีคนรับเรื่องปัญหาประจำวัน 1 คน รวมทุกเรื่องไว้ที่เดียว — ไม่กระจายทางแชท
  • ประชุมสั้น 15 นาทีทุกเช้าใน 5 วันแรก
  • ระบบเดิม (ถ้ามี) เป็นอ่านอย่างเดียวเท่านั้น — ห้ามบันทึกเพิ่ม
  • ห้ามบันทึกซ้ำสองระบบพร้อมกัน — ข้อมูลจะแตกเป็นสองชุดภายในวันเดียว รวมกลับแทบไม่ได้

ทบทวน

  • ผลที่ยังไม่อนุมัติ พิมพ์ได้ไหม? — ไม่ได้ กันผลหลุดออกไปก่อนมีคนตรวจสอบ
